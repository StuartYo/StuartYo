Claude 上手指南

給生科系同學的 30 分鐘入門 ・ 用 Claude 應付大學課業
先講重點（只記這 5 件事就夠）
  1. 要從 Chat 切到 Code 介面，Code 才能真的「幫你動手」：讀你的資料夾、做網站、產 PDF/簡報。
  2. 建一個專門放課業資料的資料夾，讓 Code session 只在那裡工作。
  3. 那個資料夾只放課業內容，所以可以開 Bypass permissions，省掉一直按「允許」。
  4. 日常用 Sonnet 5.5 就好，20 美金方案用量比較不會爆。
  5. Claude 不是答案機，是教練：叫它出題考你、講解、做成你看得懂的東西。

1. Chat 和 Code 差在哪

Chat（聊天）Code（程式碼）
像什麼一問一答的家教坐在你電腦旁、會動手做事的助教
能做問問題、解釋、改文章讀整個資料夾的講義、批次整理、產出 PDF / Word / PPT / Excel、直接建學習網站並上線
適合臨時問一個概念整學期、整門課的長期工作

Claude 網頁或 App 左上角/上方有 Chat / Code 的切換，切到 Code 就是了。（介面文字偶爾會改版，找不到就問 Claude「Code 在哪」。）

2. 它能幫你做的事（生科系很適合）

你的科目可能有很多「圖」和「大量記憶」（細胞構造、代謝路徑、解剖、分類、實驗流程⋯）。這裡是我的猜測，實際請依你的課調整：

  • 講義變複習網站：把老師的 PDF 丟進去，請它做成有測驗、可翻卡、可自我評分的互動網站，手機打開就能背。
  • 圖片記憶：把課本圖做成「遮住標籤讓你猜」的閃卡；請它為難記的路徑編口訣、比喻、記憶宮殿。
  • 出題考你：依範圍出選擇、填空、簡答題，錯的自動加強再考。
  • 整理筆記：上課錄音逐字稿、投影片 → 條理清楚的重點筆記＋名詞表。
  • 實驗報告與數據：整理數據、跑統計、畫圖（R / Python 它都會），並解釋每一步為什麼。
  • 讀文獻：丟英文論文，請它用白話講摘要、方法、限制，再逐段問。
  • 報告與簡報：產 Word、PPT、Excel，或直接接 Canva 排版。
想找靈感？可以直接問 Claude：「請針對我這門課，列出 5 種最適合我的學習方式，並各舉一個馬上能做的例子」。也可以問：「Anthropic 官方有推薦哪些學習用法？」，它會幫你查。

3. 建立你的「課業工作區」（最推薦的做法）

  1. 在桌面新增資料夾，例如 大學課業，裡面再分科目：細胞生物學/、生化/⋯，把講義、課本 PDF、考古題放進去。
  2. 開一個新的 Code session，工作資料夾選那個 大學課業。
  3. 把這份 PDF 丟給它，說：「這是我朋友給的入門指南，我是中興生科系學生，請先讀完，再照第 4 節幫我設定。」
  4. 權限模式選 Bypass permissions。
為什麼可以開 Bypass？為什麼要小心？
Bypass 代表 Claude 做事不再逐項問你。因為資料夾裡只有課業檔案，最壞也只是弄亂講義，風險很低，換來很快的工作流程。
守則：① 資料夾裡不要放密碼、身分證、私人照片；② 重要原檔先備份一份；③ 不要拿這個模式去開工作資料夾以外的東西。

4. 一開始要裝的東西（Skills 與 Connectors）

Skills：讓 Claude 多一套專業本事

優先裝跟「文件處理」有關的官方 skill：

  • pdf：讀 PDF、合併、拆分、擷取圖片/表格、掃描檔 OCR。
  • docx / pptx / xlsx：Word 報告、簡報、Excel 資料表。
  • 學習類：lecture-coach（互動式講義讀書教練）、learn（教學、閃卡、測驗）。

怎麼裝：直接對 Claude 說「請幫我搜尋並安裝適合大學生的官方 skill，特別是文件處理（PDF、Word、PPT、Excel）和學習類」，它會列出來讓你確認。也可以在設定裡找 Skills / Plugins 自己加。

Connectors：把你的其他服務接進來

服務拿來做什麼怎麼接
Google 雲端硬碟直接讀你的講義、筆記，產出存回去設定 → Connectors → 選 Google Drive → 登入授權
Canva做海報、簡報、圖解，排版好看設定 → Connectors → 選 Canva → 授權
Vercel把你做的複習網站一鍵免費上線，得到網址，手機平板都能開先註冊 vercel.com 帳號，再到 Connectors 加 Vercel；或請 Claude 引導你部署

選單位置可能因改版而不同，找不到就直接問 Claude：「怎麼接 Google Drive？」它會一步步教你。

5. 選哪個模型

模型什麼時候用
Sonnet 5.5（預設用這個）日常 90% 的事：讀講義、出題、寫報告、做網站。速度快、用量省。
Opus / 更大的模型很難的推理、大型專案、複雜數據分析才切換。用量消耗比較快。

你的 20 美金/月方案有用量上限，全程用 Sonnet 5.5 比較不容易在期中考週爆量。省用量小技巧：一個主題開一個 session、不要在同一段對話塞太多不相關的事、需要時請它「摘要目前進度」再開新對話。

6. 為什麼值得用 Claude（跟 Gemini 比）

以下是大多數使用者的經驗，不是絕對，每個模型都會進步，也都會出錯：

  • 比較會承認「我不確定」：遇到不懂的事比較不會硬掰，但仍可能出錯。
  • 長文件處理穩定：整本講義、整篇論文可以一起丟，並能在長對話中維持前後一致。Code 模式更是直接在檔案裡工作，不必把內容全塞進對話窗。
  • 會動手做事：不只給建議，而是直接生成檔案與網站。
所以還是要驗證：
① 專有名詞、數字、作用機制，拿課本/講義對一次；
② 叫它標出出處（「這是講義第幾頁？」）；
③ 覺得怪就反問「你確定嗎？依據是什麼？」；
④ 作業與報告的學術誠信要自己把關：讓它教你、幫你改，但內容與思考要是你自己的，並遵守課堂規定。

7. 第一個 session 可以直接貼的起手式

我是國立中興大學生命科學系的學生，想用 Claude 幫我讀書。這個資料夾放我所有課業資料。
請先：
1. 掃描資料夾，告訴我有哪些科目和檔案；
2. 幫我安裝適合大學生的官方 skill（PDF / Word / PPT / Excel 與學習類）；
3. 問我 3 個問題，了解我的學習習慣（例如比較會看圖還是看字、考試型態）；
4. 依照我的答案，推薦最適合我的 3 種學習方式，並先幫我對其中一科做出範例（例如互動複習網站）。
請用繁體中文，語氣簡單好懂。

8. 用得更好的 5 個習慣

  1. 給脈絡：說明科目、考試範圍、老師的重點。
  2. 叫它出題考你，而不是只叫它整理：主動回想比重複閱讀有效。
  3. 做完就存：好用的網站、筆記存進資料夾，下學期還能用。
  4. 大任務分步：「先做大綱→我確認→再做完整」。
  5. 卡住就直接問 Claude 怎麼用 Claude：它很會教。
