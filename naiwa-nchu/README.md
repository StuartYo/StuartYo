# 🐸 奶蛙興大巡迴賽

中興大學校內活動網站：連續 120 小時，每小時奶蛙換一個校內地點，各系同學把奶蛙搬過去、拍合照開放打卡，到現場掃 QR Code 幫自己的系加分。

技術：Next.js 16（App Router）＋ PostgreSQL（Supabase）＋ Supabase Storage，部署在 Vercel。

## 活動流程（系統怎麼判斷）

1. 每個時段開始時，前台公布地點（下一站會在開始前 10 分鐘公布）。
2. 有人把奶蛙搬到現場，用網站相機拍「奶蛙＋地標＋指定手勢」合照上傳。上傳時會檢查手機 GPS 是否在地點範圍內。
3. 第一張合照上傳後，這個時段立刻開放打卡；範圍內的人選好系級就能打卡。
4. 每台裝置每個時段只能打卡一次；裝置第一次打卡後就鎖定系所。
5. 工作人員在後台審核照片：時段只要有一張通過，分數就正式生效；沒有任何通過的照片，該時段分數作廢。不合格照片直接退回，不扣分。
6. 30 分鐘沒人上傳合照，前台會顯示「奶蛙好像迷路了」，後台（和選填的 Discord）會提醒工作人員。

**計分**：每次打卡分數 = √(各系人數中位數) ÷ √(該系人數)，限制在 0.5–3 分。人數用 114 學年度教育部公開資料，後台可改。

## 第一次設定

### 1. Supabase

1. 建立專案（地區選 Tokyo / Singapore 比較快）。
2. **Storage** → New bucket → 名稱 `photos`，**不要**勾 Public。
3. 複製連線字串和金鑰，填到 `.env.local`（參考 `.env.example`）。

### 2. 建資料表並匯入地點、系所

```bash
npm install
cp .env.example .env.local   # 填好裡面的值
node --env-file=.env.local --no-warnings scripts/db-setup.mjs
```

會建立資料表，並匯入 36 個校內地點與 39 個學士班／學士學位學程。可以重複執行，不會覆蓋已存在的資料。

### 3. 本機測試

```bash
npm run dev
```

- 前台：http://localhost:3000
- 後台：http://localhost:3000/admin

手機定位只能在 HTTPS 下使用，所以要用手機實測，請部署到 Vercel 後再測。

### 4. 部署到 Vercel

匯入這個專案，在 Environment Variables 填入 `.env.example` 裡的變數，部署即可。

## 活動前的準備清單

- [ ] **後台 → 地點**：標「需確認」的地點（理學大樓、籃球場、女生宿舍、興大二村）實地走一趟確認座標。理學大樓目前是停用的。綜合大樓施工中，沒有放進來。
- [ ] 實地拿手機到幾個地點測試打卡，確認範圍半徑合適（預設 80 公尺，湖和操場 120 公尺）。
- [ ] **後台 → 設定**：填活動開始時間，按「儲存並重新排程」。
- [ ] **後台 → 時程**：看一下排出來的地點，不喜歡的可以直接改。
- [ ] **後台 → 設定**：下載 QR Code SVG，印出來護貝貼在奶蛙身上。
- [ ] 活動期間：至少一人有空就看「照片審核」。可以設 Discord webhook 收通知。
- [ ] 活動結束、確認結果後：**後台 → 設定 → 刪除定位資料**（規則頁有承諾）。

## 資料來源

- 系所人數：教育部大專校院校務資訊公開平台 學1-1「正式學籍在學學生人數－以系(所)統計」114 學年度（取自公開鏡像資料）。學院歸屬依學校現行組織人工對照。學士後醫學系也列入，若不想讓它參賽，可在後台取消勾選。
- 地點座標：OpenStreetMap 衍生資料、校內學生專案標記的 Google Maps 座標、校園共享機車與 YouBike 站點資料互相比對，多數誤差在 5–35 公尺。
